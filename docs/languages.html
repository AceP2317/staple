What Staple is made of

Written in Python, SQL and JavaScript: 15 Python files invent the history, predict parts, load trucks, ask Claude, replay dispatch, write the pages and check it all; 15 SQL files hold the tables and the 14 metric queries; 2 JavaScript files run the hints and switches. Beside them, 6 Bash scripts run the checks before each commit, and 3 HTML files and 1 CSS file lay out the pages. Nothing is installed beyond Python.

Every count on this page is read from git's list of the repository's files each time the pages are built, so a new file changes it on the next build. The counts leave out the docs folder, which holds the published copy the build writes from the rest.

In your browser

When you open a page, your browser draws it and runs its scripts. Each page carries its own styles and scripts, so it fetches nothing from any other site.

HTML

The language a web page is written in: headings, paragraphs, tables and links, which the browser lays out.

The report's HTML is written by report.py. The manuals' text and this page's sit in HTML templates, each with a named gap where a value from the code goes.

3 files: staple/pages/ 3.

CSS

The rules for how a page looks: colors, spacing, and a layout for a phone.

One stylesheet holds the light and dark colors as named tokens, and the build pastes it into every page.

1 file: staple/pages/ 1.

JavaScript

The language a browser runs inside a page, to answer a click, a tap or a key.

One script shows a hint on hover, focus or tap and runs the light and dark switch. The other switches the plan screen's day, technician and view. Neither uses a framework or fetches anything.

2 files: staple/pages/ 2.

On the builder's computer

Whoever builds Staple runs it here: python run.py invents the history and writes every result and page, python check.py runs every check, and the Bash guards run before each commit. On this machine that is Windows, with the Bash that Git for Windows ships.

Python

A general programming language, run from a terminal. Staple uses only the library Python ships with, so nothing is installed.

It invents the history, predicts parts, loads trucks, reads Claude's saved answers, replays dispatch, works the methods page's examples, writes the pages and runs every check.

15 files: staple/ 13, the top folder 2.

SQL

The language for asking a database a question. Python's own library carries SQLite, which keeps the whole invented world in one file and runs every query.

One file defines the tables, and each metric query computes one table the report is built from.

15 files: sql/ 1, sql/metrics/ 14.

Bash

The command language of a Unix shell, run here by the Bash that Git for Windows ships.

The guard runner starts the repository's guards before each commit, and each guard is one script.

6 files: scripts/ 1, scripts/guards/fast/ 5.

On GitHub's computers

GitHub keeps the repository and serves the docs folder as the public pages. After each push, GitHub Pages runs Jekyll, its site builder, over that folder. Staple's pages carry no Jekyll settings, so it copies them as they are, and check.py fresh-clone proves it by comparing the live report with the committed copy. None of Staple's own code runs there.

On Anthropic's computers

Claude Haiku 5.5 read every customer description once and wrote each follow-up question. Staple sends it the prompts the methods page prints word for word, and none of Staple's code runs there. The answers are saved in the data folder, so the pages rebuild without a key; python run.py --live asks the Claude API again with your own key.

Add-ons, and the programs Staple starts

Staple has no add-ons. Its Python imports nothing outside the library Python ships with, and check.py guards refuses an import that would need installing, so there is no list of packages to keep.

It does start 4 programs already on the builder's computer, each for one job. check.py languages finds every place the Python code starts a program and refuses one without a line here:

git
Lists the repository's files for these counts and the names scan, reads each page's build stamp from the history, and clones the public repository fresh for check.py fresh-clone.
Chrome
Photographs the share card in python run.py --card, the one build step outside Python.
Claude Code (claude)
Built the saved answers and follow-up questions with python -m staple.triage build, on a subscription rather than a key.
Bash (bash)
Runs the guard runner on a scratch folder of planted guards in check.py plain-words, which holds the runner to its arguments, its exit codes and the lines it prints.
